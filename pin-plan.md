## Cadence
- Day 1: create boards, claim website, publish 4 pins (tax-01, trade-01, tax-04, trade-03).
- Then 2 pins per day until all 12 are live; afterwards 1 new pin every 2–3 days (re-use images with new titles is allowed; Pinterest favours fresh images).
- Never pin the same image twice to the same board.

## Publishing mechanics
The browser pane can't open the file-upload dialog, so pins are created with "Save from site" from a page that hosts the images: https://remoteworksdesing.github.io/quarterlyready/pins/ (folder `pins/` in the GitHub repo + `pins/index.html` listing all images). Gustavo uploads the 12 JPGs to the repo once via GitHub → Add file → Upload files (drag and drop the folder contents into `pins/`).
